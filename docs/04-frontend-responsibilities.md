# Frontend Responsibilities

## Purpose

Administrative and user interface.

## What It Does

- Login and authentication UI
- Workspace management
- Connector management
- User management
- RBAC configuration
- Agent chat interface
- Settings pages

## What It Does NOT Do

- Does NOT perform data retrieval
- Does NOT run AI models
- Does NOT communicate with Coral directly

## Communication

Frontend communicates only with the Backend via HTTP APIs.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Design Philosophy

- Enterprise-grade aesthetics
- Operational feel
- Dense but readable layouts
- Observability-first UI
- Infrastructure dashboard aesthetics
